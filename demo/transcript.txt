StitchGauge demo transcript
===========================
A real session recorded on Linux with Python 3.11. Section A is a terminal
capture: every prompt, typed answer and line of output is exactly what the
program printed (the invalid "abc" width is rejected and re-prompted, and the
12.0 sts/in yarn lookup reports the out-of-range message). Section B is the
one-shot form of the same three calculators, captured verbatim from stdout
(the final invalid run shows its single stderr line and exit status 1).

Numbers used throughout the README:
  * 40 stitches / 56 rows over 8 x 8 inches               -> 5.00 sts/in, 7.00 rows/in
  * pattern 5 sts / 7 rows rescaled to 5.5 sts / 7.5 rows -> 110 stitches, 129 rows
  * 4.0 sts/in                                            -> Worsted (4)
